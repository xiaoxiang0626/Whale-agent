# 模型接口接入

## 解决的问题

CLI 可以通过本地配置连接 OpenAI 兼容的非流式文本服务。模型调用仍由可替换适配器负责，任务逻辑不依赖厂商 HTTP 协议。完整配置见[接入模型 API](../model-api.md)。

## 范围

- 新增 `openai-compatible` 适配器与统一工厂，默认保持离线模拟。
- 支持 `--env`、`--base-url`，并验证模型名、基础地址、密钥、超时和响应大小配置。
- 区分认证、限流、超时、网络及响应错误，不回显服务端错误正文或自动重试。
- 根据用户授权，将协作约定调整为自审和相关检查通过后自行合入。

## 阅读顺序

1. [配置解析](../../src/config.ts)：看默认模拟模式与真实接口所需字段。
2. [适配器](../../src/providers/openai-compatible.ts)：看协议转换、响应限制和取消。
3. [适配器工厂](../../src/providers/index.ts)与[命令行入口](../../src/cli.ts)：看配置如何选择实现。
4. [HTTP 测试](../../tests/openai-compatible.test.ts)和[命令行测试](../../tests/cli.test.ts)：看正常与失败场景。

## 验证

Windows、Node.js 24.15.0、pnpm 11.28.5：`pnpm check` 的 18 项测试、类型检查和构建通过。已运行构建后的命令行帮助、显式环境文件加载和模拟任务；命令行子进程也通过本地 HTTP 服务完成文本请求。

用户真实模型服务尚未验证。ChatGPT Plus 额度不会通过此适配器转换为普通 API 额度；费用和订阅差异见[模型 API 文档](../model-api.md#费用与订阅)。
