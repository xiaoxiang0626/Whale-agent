# 交互式命令行会话

你可以在终端持续输入消息，模型能够引用本次会话中成功完成的问答。当前仅处理文本，不读取或修改代码，也不执行模型生成的命令。

## 启动

先按[模型 API 指南](model-api.md)配置本地 `.env`，再运行：

```sh
my-coding-agent --env .env --interactive
```

出现 `你> ` 后输入消息并回车。模型返回后继续输入下一条消息，无需重新运行命令。真实终端中不带任务参数也会自动进入会话，例如 `my-coding-agent --env .env`。

启动时会显示[鲸鱼娘欢迎形象](mascot.md)，随后显示模型、适配器和输入提示。彩色终端使用像素字符画，窗口较小时自动缩小或改用简化字符画；设置 `NO_COLOR` 或使用非终端输出时不写入颜色控制符。

无需密钥的离线演示使用：

```sh
my-coding-agent --provider mock --interactive
```

离线适配器会明确标注模拟响应，只回显本次输入。原来的单次调用 `my-coding-agent --env .env "你的任务"` 仍可使用。显式交互选项与位置参数不能同时提供。

## 命令与退出

| 操作 | 行为 |
| --- | --- |
| 输入文本并回车 | 等待完整回复，再处理下一条输入 |
| 空白行 | 不发送模型请求 |
| `/help` | 显示命令帮助 |
| `/clear` | 清空本次上下文，下一条消息开启新话题 |
| `/exit` | 退出会话 |
| 请求期间 Ctrl+C | 取消当前请求，保留原上下文并继续等待输入 |
| 空闲时 Ctrl+C，或请求取消后再次 Ctrl+C | 退出会话 |
| 输入流结束 | 等待当前请求和已接收的行处理完成，再退出 |

命令与文本按输入顺序处理。要立即取消正在进行的请求，请使用 Ctrl+C。以 `/` 开头的未知命令会显示提示，不发送给模型。

## 上下文与失败

只有成功完成的用户输入与助手回复成对加入历史。请求失败或取消时，后续请求仍使用此前的成功历史；迟到回复不会被显示或加入历史。失败诊断不回显任意底层异常，之后可以继续输入。

历史只保留在当前进程中，退出后消失。当前没有自动压缩或恢复；对话过长导致模型拒绝时，可用 `/clear` 开始新话题。每轮都会发送当前历史，真实 API 会按服务商规则计费。

## 非终端调用

脚本或管道需要显式指定 `--interactive`。输入结束后仍会处理已经收到的行，`/exit` 之后的行不会提交。非终端环境中无参数运行会显示帮助，保留现有脚本的单次调用行为。

## 实现与验证

[Conversation](../src/conversation.ts)管理成功历史、取消后提交规则和并发拒绝；[终端会话](../src/interactive.ts)管理逐行输入、命令和 readline 生命周期；[CLI](../src/cli.ts)选择单次或交互模式。

自动化测试覆盖多轮上下文、清空、失败恢复、取消、并发拒绝、输入先结束与子进程退出。另使用本地 DeepSeek 配置验证了两轮上下文引用、清空、帮助和退出。测试与文档不保存真实密钥。
