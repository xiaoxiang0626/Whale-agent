# PR 001：建立 CLI 与可替换模型适配接口

## 解决的问题

建立可以独立运行和验证的项目起点，让后续接入自己的模型 API 时，协议转换集中在适配器中。当前通过本地模拟响应演示一次调用，没有连接真实模型，也不能自动修改代码。

## 本次改动

- 创建独立 TypeScript ESM 项目，提供源码启动、类型检查、测试和构建命令。
- 定义文本消息、模型请求、响应与 `ModelProvider` 接口。
- 增加任务入口、离线适配器、配置优先级、CLI 错误处理和取消信号传递。
- 提供中文启动、架构、开发和后续 PR 文档。

## 验收

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm dev "解释这个项目"
pnpm start "解释这个项目"
```

源码和构建后的 CLI 都应显示模拟标记。不能把该输出当作真实 API 验证证据。

本地验证环境为 Windows、Node.js 24.15.0、pnpm 11.28.5。已执行 `pnpm check`，9 项测试通过，类型检查与构建通过；同时运行了帮助命令、源码 CLI、构建后的 CLI 和显式 `.env` 加载示例。真实 API 尚未接入，未进行真实 API 验证。
