# 鲸鱼娘欢迎形象

## 解决的问题

交互 CLI 启动时显示参考图风格的鲸鱼娘。彩色终端使用本地像素字符画，无色或窄窗口使用简化字符画。使用方式与终端规则见[终端形象](../mascot.md)。

## 设计

44×44 像素色码保留头饰、蓝发、眼睛、围裙和鲸鱼尾巴。渲染器用半块字符组合像素，并按终端尺寸和颜色能力选择输出。形象只在交互启动时显示，不加入模型上下文，不增加模型请求或运行依赖。

## 验证

`pnpm check` 的 26 项测试、类型检查和构建通过。构建后的离线 CLI 显示形象并完成帮助和退出。彩色输出已转换为预览检查，尺寸、字节数和无色输出结果见[开发日志](../development-log.md)。

当前环境的伪终端创建限制延续交互会话阶段的记录。已验证实际渲染内容和尺寸选择，未将预览替代为对用户终端颜色能力的实测。
