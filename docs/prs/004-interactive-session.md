# 交互式 CLI 会话

## 解决的问题

用户启动命令后可以持续输入并引用前文。交互入口、帮助、清空、取消与退出规则见[使用说明](../interactive.md)。

## 设计

`Conversation` 接收模型适配器并保存成功问答。一次请求成功后才成对提交用户输入和助手回复；失败或取消保留旧历史。同一实例拒绝并发调用或在请求期间清空。

终端层通过 readline 逐行处理输入，独立负责会话命令、取消和关闭。单次任务也通过 `Conversation` 发送一次请求。模型接口和 HTTP 协议保持原有职责。

## 验证

Windows、Node.js 24.15.0、pnpm 11.28.5：`pnpm check` 的 26 项测试、类型检查和构建通过。构建产物使用本地 DeepSeek 配置完成两轮对话，第二轮正确引用第一轮给出的暗号，并完成清空、帮助和退出。

自动化测试使用离线适配器和本地 HTTP 服务，不需要密钥。真实服务验证单独执行，未提交或打印凭据。会话只保存在内存中，没有持久化、自动压缩或代码工具。
