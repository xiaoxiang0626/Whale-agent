# 阶段 011：会话日志、恢复与上下文管理

退出后需要接续任务，同时避免重新执行已经发生的文件或命令操作。本阶段增加命名 JSONL 日志和恢复入口，完整记录实际模型请求、响应与确认操作结果；请求和操作前先刷盘，失败后停止后续工作。恢复使旧提案失效；未记录完成的确认操作标记未知并禁止继续副作用。

使用版本 1 格式和递增序号，验证运行身份、工具调用配对与字段；独占锁阻止并发写入。未完成末行须显式选择备份后修复，其他损坏不猜测。上下文按字符预算省略最早完整轮次，保留当前调用与结果，完整历史继续存档。

阅读顺序：[使用与恢复规则](../sessions.md) → [日志](../../src/session.ts) → [上下文选择](../../src/context.ts) → [会话](../../src/conversation.ts) → [日志测试](../../tests/session.test.ts)及[上下文测试](../../tests/context.test.ts)。

验证：`pnpm check`（61 项测试）、构建后启动、`pnpm test:tui:pty`、`pnpm test:session:pty`、`pnpm test:session:live`、文档、打包与差异检查。真实模型完成临时文件工具历史恢复；合成历史请求由 10914 降至 2856 个 JSON 字符，省略 12 条消息，服务返回 prompt token 从 1394 降至 400。数据仅对应此样例，不推断真实编码任务质量或整体性能。

限制：日志按需开启、未加密、最多 128 MiB；完整历史驻留内存。没有自动检索或语义摘要，不提供操作系统隔离、后台任务或多文件事务。当前路线的 001–011 已交付，MCP、多 Agent、插件体系等不包含在本次范围。
